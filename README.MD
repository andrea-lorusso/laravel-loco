# Installation

Clone (or fork the repository):

```
git clone https://github.com/andrea-lorusso/laravel-loco.git
```

Open **Visual Studio Code** (VSC). After some seconds a popup will ask to "Open in devcontainer". If the popup doesn't appear open the command console <kbd>cmd</kbd> + <kbd>shift</kbd> + <kbd>P</kbd> (this is for OS systems - use <kbd>ctrl</kbd> + <kbd>shift</kbd> + <kbd>P</kbd> for Windows ones) and search for the command "Dev Containers: Reopen in Container" this will restart the VSC windoww, build necessary containers and let VSC operate directly into the main container.

Once completed all should be ready for development. Application is available at [https://lvh.me/](https://lvh.me/) address.
